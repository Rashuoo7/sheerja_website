# Sheerja Marine Services Website

Static HTML website for **Shreeja Marine Services** — a Mumbai-based company providing comprehensive shipping solutions including technical management, crew management, marine insurance, and more.

## Structure

- `index.html` — Homepage
- `about-us/` — About Us page
- `contact-us/` — Contact Us page
- `services/` — Services landing + individual service pages
- `wp-content/` — Assets (CSS, JS, images, plugins)

## Notes

This is a recovered static mirror of the original WordPress/Elementor site. All pages are self-contained HTML files with local asset references.
